# Bounty Harvest 0.11.0

This beta revives Bounty Harvest as a reproducible client and dedicated-server release while repairing the Level 1–8 progression.

## Progression

- Restored the Research and Levels quest chapter.
- Made the Bounty Board and a first completed bounty mandatory onboarding before Level 2.
- Rebalanced level gates around earned currency and representative milestones instead of large item-deletion and mob-drop taxes.
- Removed poisonous-potato RNG from the main path and made it an optional rewarded challenge.
- Moved string to Level 3 so the bow can be crafted when its quest appears.
- Preserved the Level 4 egg-based wheat-dough recipe.
- Added a genuine copper era; completing copper tools unlocks the new Ironworking stage.
- Staged vanilla iron equipment and added deliberate entry stages for Create, Alex's Caves, Twilight Forest, Alex's Mobs, and Cooking for Blockheads.
- Converted level rewards to auto-claimed FTB Quests stage rewards.
- Added direct crafting-table coin exchange and clearer progression tooltips.

## Reliability and release engineering

- Added Polymorph, Controlling, ModernFix, and FerriteCore metadata.
- Removed Biotech and its NsTut Lib dependency, and removed the legacy Nether's Delight 4.0 add-on after its registry API proved incompatible with the updated Farmer's Delight 1.3 ecosystem.
- Added pinned Minecraft, Forge, Java, CurseForge project, and version metadata.
- Added reproducible CurseForge client and dedicated-server builders with client/server filtering and checksums.
- Added Windows and Unix server launchers, validation, archive verification, PR CI, server smoke testing, GitHub Releases, and CurseForge publishing.
- Cleaned stale IDs, mismatched quest counts, archived chapters, and local JEI world data.
