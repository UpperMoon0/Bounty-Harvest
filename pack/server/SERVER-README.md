# Bounty Harvest dedicated server

This archive contains the server-compatible mods, configuration, quests, CraftTweaker scripts, KubeJS content, and Bountiful data pack for Bounty Harvest.

Requirements:

- Java 17
- At least 6 GB RAM recommended

Windows: run `start-server.bat`.

Linux/macOS: run `chmod +x start-server.sh`, then `./start-server.sh`.

The first launch installs Forge and creates `eula.txt`. Read Mojang's EULA and change `eula=false` to `eula=true` only if you agree, then launch again. This pack never pre-accepts the EULA.

Worlds, logs, backups, client-only mods, and player data are not included.
